# Технічна специфікація (specs.md): Лендинг кафе «Вечірній вокзал»

## 1. Загальний опис проєкту
* **Назва:** Односторінковий сайт-візитка (Landing Page) для кафе «Вечірній вокзал».
* **Локація:** м. Львів, пл. Двірцева (поблизу Головного залізничного вокзалу).
* **Цільова аудиторія:** Пасажири поїздів, туристи, водії, працівники залізниці та місцеві жителі, які шукають цілодобову (24/7) гарячу домашню їжу.
* **Основний стек:** HTML5, CSS3, BootStrap (змінні, Flexbox, CSS Grid), Vanilla JavaScript (ES6+).
* **Хостинг:** GitHub Pages.

---

## 2. Структура сторінки та DOM-елементи

### 2.1. Dynamic Holiday Warning Banner (`#holidayBanner`)
* **Призначення:** Інформування про святковий графік роботи або особливості замовлень.
* **Елементи:** Текст попередження, кнопка закриття (`#closeBannerBtn`).

### 2.2. Навігаційна панель (`header.navbar`, `#navbar`)
* **Бренд-блок:** Логотип з іконкою поїзда (`fa-train`), назва та підзаголовок.
* **Індикатор статусу (`#liveStatusPill`):** Візуальний бейдж «Відчинено 24/7» із пульсуючим/зеленим маркером `.status-dot`.
* **Меню навігації (`#navMenu`):** Якірні посилання (`#hero`, `#about`, `#menu`, `#reviews`, `#location`).
* **Дії:** Кнопка швидкого виклику (`#callNavBtn`, посилання `tel:`) та кнопка мобільного меню (`#mobileToggle`).

### 2.3. Головний екран (`section#hero`)
* **Фон:** Оверлей поверх зображення.
* **Контент:**
  * Бейдж локації («2 хвилини від Залізничного Вокзалу»).
  * Заголовок `H1` з акцентом на цілодобовість.
  * Блок рейтингу (3.3 / 5.0 на базі відгуків Google Maps).
  * CTA-кнопки: перехід до меню (`#menu`) та маршруту (`#location`).
* **Промо-картка:** Картка з подарунком («50г та канапка від Пані Лесі») та зображенням фірмового борщу.

### 2.4. Переваги закладу (`section.features-section`)
* **Формат:** 4-колонкова сітка карток переваг (`.grid-features`):
  1. Цілодобовий графік (24/7).
  2. Справжня домашня кухня.
  3. Чистота та білі скатертини.
  4. Доступні ціни поруч із вокзалом.

### 2.5. Блок «Про нас» (`section#about`)
* **Формат:** Двоколонкова сітка (`.grid-about`):
  * **Ліворуч:** Галерея з двох фотографій (інтер'єр та атмосфера).
  * **Праворуч:** Опис закладу, маркований список переваг з іконками `fa-check-circle`, цитата-відгук гостя.

### 2.6. Меню страв (`section#menu`)
* **Фільтрація (`.menu-tabs`):** Категорії `all`, `soups`, `mains`, `compliments`, `desserts`.
* **Картки страв (`.menu-card`):**
  * Зображення (опціонально), бейджі (`Хіт продажів`, `Подарунок 🎁`).
  * Назва, ціна (або `0 ₴` для безкоштовного компліменту).
  * Опис, вага порції, кнопка замовлення з подією `onclick="orderItem('...')"` / `.gift-btn`.

### 2.7. Відгуки Google (`section#reviews`)
* **Зведена картка (`.reviews-summary-card`):**
  * Середній бал (`3.3`), золоті зірки, загальна кількість відгуків.
  * Прогрес-бари розподілу оцінок від 1★ до 5★.
  * Кнопка відкриття модального вікна додавання відгуку (`#openReviewModalBtn`).
* **Сітка карток відгуків (`#reviewsGrid`):** Аватарки-ініціали, імена, дати публікації, оцінка зірками, текст відгуку та тематичні теги (`.review-chip`).

### 2.8. Локація та Контакти (`section#location`)
* **Інформаційний блок:** Адреса (пл. Двірцева), графік (24/7), клікабельний номер телефону, список найближчих орієнтирів (хмара тегів).
* **Інтерактивний макет карти (`.map-container`):** Візуальний мокап із пульсуючим піном (`.pulse-pin`), спливаючим вікном та кнопкою переходу до повноцінного Google Maps.

### 2.9. Підвал (`footer.footer`)
* Інформація про заклад, дублююча навігація, бейдж хостингу на GitHub Pages, копірайт (2026).

### 2.10. Модальне вікно відгуку (`#reviewModal`)
* Спливаюче вікно для створення нового відгуку.
* **Поля форми (`#addReviewForm`):**
  * Текстове поле імені (`#reviewerNameInput`).
  * Інтерактивний вибір рейтингу 1–5 зірок (`#starSelect`).
  * Текстове поле відгуку (`#reviewTextInput`).
  * Кнопка відправки.

## 3. Функціональні вимоги до JavaScript (`script.js`)

| Модуль | Тригер / Подія | Очікувана поведінка |
| :--- | :--- | :--- |
| **Holiday Banner** | Клік на `#closeBannerBtn` | Приховує банер, зберігає стан закриття в `localStorage` / `sessionStorage`. |
| **Мобільне меню** | Клік на `#mobileToggle` | Тоглить клас `.open` на `#navMenu`, анімує іконку (бургер $\leftrightarrow$ хрестик). |
| **Фільтрація меню** | Клік на `.tab-btn` | Перемикає активний клас, фільтрує `.menu-card` за значенням `data-category`. |
| **Швидке замовлення** | Виклик `orderItem(itemName)` | Відкриває діалог підтвердження або ініціює дзвінок/перехід до месенджера з попередньо введеною стравою. |
| **Модальне вікно** | Клік на `#openReviewModalBtn` / `#closeModalBtn` | Показує / приховує `#reviewModal`, блокує прокрутку сторінки (`overflow: hidden` на `body`). |
| **Рейтинг у формі** | Клік/Hover на зірки в `#starSelect` | Динамічно підсвічує зірки від 1 до вибраного індексу. |
| **Додавання відгуку** | Submit форми `#addReviewForm` | Запобігає перезавантаженню сторінки (`preventDefault`), валідує поля, додає картку у `#reviewsGrid`, оновлює лічильник та закриває модал. |
